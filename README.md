# نبض السوق — السيرفر الحقيقي (Backend)

هذا سيرفر حقيقي يشتغل خارج أي بيئة معاينة، فيحل مشكلة "Failed to fetch" نهائياً
لأنه مش محجوب عن الإنترنت.

## ما هو حقيقي فعلياً هنا
- إنشاء حساب وتسجيل دخول بكلمة مرور مشفّرة حقيقياً (bcrypt) + قاعدة بيانات فعلية (SQLite)
- حد الثلاث تحليلات المجانية مُطبَّق من قاعدة البيانات على السيرفر — لا يمكن تجاوزه بمسح بيانات المتصفح
- أسعار حية حقيقية لأكبر 50 عملة رقمية + أهم أزواج الفوركس (تُجلَب من السيرفر فلا تصطدم بقيود CORS)
- تحليل شارت حقيقي بالذكاء الاصطناعي، بمفتاح API سري محفوظ على السيرفر فقط (غير مكشوف لأي زائر)

## ما يحتاج خطوة إضافية منك (اشتراكات مدفوعة)
الأخبار، التقويم الاقتصادي، وتتبع الحيتان تحتاج منك تسجيل حساب في:
- الأخبار: newsapi.org أو benzinga.com
- الاقتصاد: tradingeconomics.com
- الحيتان: whale-alert.io أو nansen.ai

بعد ما تجيب المفتاح، تحطه في ملف `.env`، وأنا أبني لك مسار (route) جديد يستخدمه — هذا الجزء بسيط ومباشر بمجرد ما يصير عندك المفتاح.

## التشغيل محلياً للتجربة
```bash
npm install
cp .env.example .env
# افتح .env واملأ JWT_SECRET و ANTHROPIC_API_KEY على الأقل
npm start
```
السيرفر يشتغل على http://localhost:3000

## النشر الحقيقي (اختر واحدة)
- **Render.com** — الأسهل، فيه خطة مجانية، يدعم SQLite مع قرص دائم (Persistent Disk)
- **Railway.app** — سهل جداً، ربط GitHub مباشرة
- **VPS خاص** (DigitalOcean/Hetzner) — أكثر تحكماً، يحتاج خبرة أكبر بإدارة السيرفرات

في كل الحالات: تضيف متغيرات البيئة (نفس محتوى `.env`) من لوحة تحكم الاستضافة، مش برفع ملف `.env` نفسه لـ GitHub أبداً.

## نقاط الوصول (API Endpoints)
| المسار | الطريقة | الوصف |
|---|---|---|
| `/api/auth/signup` | POST | إنشاء حساب `{name, email, password}` |
| `/api/auth/login` | POST | تسجيل دخول `{email, password}` |
| `/api/me` | GET | بيانات المستخدم الحالي (يحتاج Header: `Authorization: Bearer <token>`) |
| `/api/prices` | GET | أسعار حية (كريبتو + فوركس) — بدون حاجة لتسجيل دخول |
| `/api/analyze` | POST | تحليل شارت `{imageBase64, mediaType}` — يحتاج تسجيل دخول |

## الخطوة التالية
بعد ما تنشر هذا السيرفر وتاخذ رابطه (مثلاً `https://your-app.onrender.com`)، عدّل ملف الواجهة الأمامية (الـ HTML) ليستدعي هذا الرابط بدل الاتصال المباشر — وحينها كل شيء بالمنصة يصير حقيقي 100% فعلياً.
